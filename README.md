# Body Space — сайт-прототип

Сайт мережі масажних студій Body Space (Київ). Звичайні файли HTML, CSS і
JavaScript: нічого встановлювати й збирати не треба.

## 1. Як відкрити сайт на комп’ютері

**Найпростіше:** у Finder двічі клацніть `index.html` — сайт відкриється в
браузері. Усе працює, крім карт на сторінці «Студії» (Google іноді не показує
їх з локального файлу) — після публікації вони з’являться.

**Як на справжньому сайті** (зручно для перевірок):
1. Відкрийте Термінал у цій папці (у Finder: правий клік на папці →
   «Нові термінали в папці» або «Services → New Terminal at Folder»).
2. Введіть `python3 -m http.server 8000` і натисніть Enter.
3. У браузері відкрийте `http://localhost:8000`.
4. Щоб зупинити — у Терміналі натисніть Ctrl + C.

## 2. Як опублікувати на Netlify

**Варіант А — перетягнути папку (5 хвилин):**
1. Зайдіть на https://app.netlify.com і увійдіть.
2. Відкрийте **Sites → Add new site → Deploy manually**.
3. Перетягніть у вікно **всю папку** `Body space` (з `index.html` усередині).
4. Через хвилину Netlify дасть адресу на кшталт `назва.netlify.app`.
   У **Site configuration → Change site name** можна поставити `bodyspace`.

**Варіант Б — через GitHub (кожна зміна публікується сама):**
1. Створіть репозиторій на GitHub і завантажте в нього цю папку
   (вона вже є git-репозиторієм — потрібні лише `git remote add` і `git push`).
2. У Netlify: **Add new site → Import an existing project → GitHub**,
   оберіть репозиторій. Build command — порожньо, Publish directory — `/`.
3. Тепер кожен `git push` оновлює сайт.

**Після публікації** замініть адресу `https://bodyspace.netlify.app/` на
справжню (якщо вона інша) у файлах: усі `*.html` (рядки `canonical` і
`og:`), `sitemap.xml`, `robots.txt`. Найпростіше — пошук і заміна у VS Code
(Cmd + Shift + H).

## 3. Де міняти ціни, майстринь і посилання Altegio

Усе лежить в одному файлі: **`assets/js/data.js`**. Змінили там — змінилося
на всіх сторінках.

- **Ціни послуг** — розділ `services`. У кожної послуги:
  `durations: [45, 60]` — тривалості в хвилинах,
  `price: { top: [1150, 1300], lead: [1300, 1500] }` — ціни топ- і провідної
  майстрині в тому ж порядку. Якщо ціна одна для всіх — `price: { all: [1200] }`.
- **Ендосфера і курси** — розділ `endosphere` (точні суми курсів 1 / 5 / 10)
  і `courses` (знижки, термін дії, подарунок).
- **Майстрині** — розділ `masters`: ім’я, студія (`studios`), рівень (`tier`:
  `"top"` — топ, `"lead"` — провідна), рік початку практики (`since`),
  спеціалізації (`specs`), цитата, робочі дні (`days: ["Пн", "Ср", "Пт"]`).
  Фото — у `assets/img/masters/` (WebP, 360×450 і @2x 720×900).
- **Відгуки** — розділ `reviews`: текст, дата, оцінка і `master` (id майстрині).
- **Студії** — розділ `studios`: адреса, години (`hours: [9, 21]`), рейтинг
  Google, телефон, підказка «як дістатися».
- **Посилання Altegio** — у кожної студії `altegioId` (номер філії), у кожної
  майстрині `altegio: { obolon: 2891770 }` (номер майстрині в цій студії).
  Сайт сам збирає посилання виду
  `https://n803030.alteg.io/company/754773/personal/menu?o=m2891770` —
  запис одразу до потрібної майстрині.

## 4. Куди вставити ID Formspree (форма сертифіката)

1. Зареєструйтесь на https://formspree.io і створіть форму (New form) —
   на пошту власниці.
2. Formspree дасть адресу на кшталт `https://formspree.io/f/xyzabcd`.
   Вам потрібна остання частина: `xyzabcd`.
3. У **`assets/js/data.js`** знайдіть рядок
   `const FORMSPREE_ID = null;
   і замініть на `const FORMSPREE_ID = "xyzabcd";`.
4. Поки ID не вставлено, кнопка «Надіслати заявку» копіює текст замовлення і
   відкриває Direct — тобто сайт працює й без Formspree.

Безкоштовний тариф Formspree — 50 заявок на місяць, цього для сертифікатів
вистачить на старт.

## Що де лежить

- `index.html` і 8 сторінок у корені; `sitemap.xml`, `robots.txt`
- `assets/css/` — `tokens.css` (кольори, шрифти, відступи), `base.css`,
  `components.css`, `pages.css`
- `assets/js/` — `data.js` (дані), `main.js` (шапка, вибір студії,
  лінія, анімації), `concerns.js`, `pricing.js`, `calculator.js`, `quiz.js`,
  `masters.js`, `certificate.js`, `shop.js`
- `assets/img/` — фото у WebP; `assets/video/` — відео зі сторіс
- `docs/` — інвентаризація контенту, запити до власниці, звіти перевірок
